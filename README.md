### 文件以及文件夹介绍：

> <u>**记得看 LTW项目启动.md 里面的注释，我应该写的挺清楚的**</u>

1. **data**：

   > **anime**：动漫页。
   >
   > - 一般不管他，或者有什么推荐的也可以自己<u>根据注释</u>改一下
   >
   > **devices**：设备页。
   >
   > - 一般不管他，我也不知道加了有什么用，留着吧
   >
   > **diary**：日记页
   >
   > - 类似于那种带图片的笔记，也可以弄但是其实如果不是那种很<u>历史性的事件</u>的话可能会容易降低该页面的价值
   >
   > **friends**：友链页
   >
   > - 用来放自己的网页的链接的地方
   >
   > **projects**：项目页
   >
   > - 有项目的话也可以扔上去，源代码跟链接页没有的话挂视频或者个人主页页差不多了
   >
   > **skills**：技能页
   >
   > - 真的要写的话记得把<u>自己的联系方式打在注释</u>上，有格式，真有人问的话我也好回答，或者直接就别管这个
   >
   > **timeline**：时间线页
   >
   > - 也是尽量放一些具有<u>里程碑意义</u>的事情，避免太冗杂了

2. **images：**

   > 配合posts存放的资源数据，详情参考一下md文档怎么写

3. **post：**

   > 主要推文地方，有一些规则：
   >
   > - \_public里面的是<u>全局性</u>的东西，就是<u>不分家</u>的内容，比方说链接收集
   > - 然后可以根据自己的情况去新建文件夹（最好是新建组织的文件夹，没有组织的把md文件放在\_personal，避免重名，请在内容后面加上自己的名字，这个用中文应该也没事）
   > - 然后组织内的文件夹可以自己随意分级，**<u>强烈不建议用中文</u>**

4. **spec：**

   > 特殊页的地方
   >
   > about：关于页面
   >
   > friends：友链界面的页脚
